# 振り返り全体へのひとこと

アプリ更新前にSupabase SQL Editorで `004_review_comments.sql` を実行してください。`003_agreement_steps.sql` も必要です。この環境からSQLの適用は行っていません。

新しい `review_comments` テーブルに家庭・本人・振り返り日ごとに1件保存します。約束には紐づけません。任意入力（500文字まで）で、既存の振り返り回答と同じ家庭内共有範囲です。アプリはふたりの回答がそろった結果画面で相手のひとことを表示します。

実機確認:

1. 最後の約束に回答し「最後に、ひとこと」で全体へのコメントを入力して保存する。
2. ふたりの回答がそろった結果画面で、書いた人の名前とともにコメントが表示されることを確認する。
3. 翌日以降、過去の振り返りを開いて同じコメントを参照できることを確認する。
4. 空欄でも完了できること、501文字以上では保存できないことを確認する。
