# 約束ごとの「やってみること」

アプリ更新前に、Supabase SQL Editorで `003_agreement_steps.sql` を実行してください。新しい `agreement_steps` テーブル・索引・家庭内の閲覧権限・本人の保存権限を追加します。既存の約束や記録は変更しません。

新しいアプリはこのテーブルを読み書きします。未適用の場合、クラウド同期は失敗します。SQLはこの作業環境から本番に適用していません。

適用後の確認:

1. 端末Aで約束の詳細から「やってみること」を保存する。
2. 端末Bの同じ家庭で更新し、同じ約束の詳細に表示されることを確認する。
3. 別の約束の詳細には表示されず、約束の件数も増えないことを確認する。
4. 振り返り結果から追加した場合も同じ約束に表示され、振り返りの日付が残ることを確認する。

以前の実装で独立した約束として保存した項目は自動変換しません。メモ内のタイトルだけでは元の約束を確実に特定できないためです。
